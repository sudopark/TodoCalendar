# 기본 제공 컬러 테마

앱 본체 전 화면에 거는 기본 제공 컬러 테마의 정본이다. 상위 작업은 #461 (C4 컬러 테마 확장)이다.

- 범위는 본체 앱 전 화면이다. 위젯과 공유 확장은 테마를 안 받는다.
- 테마마다 팔레트가 하나다. 시스템 다크모드 추종은 기존 `systemTheme` 이 계속 맡는다.
- 유저가 테마를 만드는 경로와 과금 제한은 이 문서의 범위 밖이다 — 다음 국면 소관이다.
- 설정 화면의 저장·복원은 `docs/spec/settings.md` §5 가 다룬다.

## 1. 컨셉

라인업은 23개다. 밝은 계열 11개와 어두운 계열 12개로 나뉜다. 후보 22개와 널리 쓰이는 에디터·앱 테마 레퍼런스 14개에서 비슷한 짝을 합쳐 골랐다 (유저 확정 2026-09-20). 짝을 합칠 때는 인지도 있는 레퍼런스 이름을 남겼고, 그때 흡수한 후보를 마지막 칸에 적었다.

**강조색 변경**이 "예"인 테마는 `accent` 와 `primaryBtnBackground` 까지 바꾼다. 지금 라이트·다크는 둘 다 시스템 파랑을 쓰므로, 이 테마들은 버튼과 강조 요소 전반의 인상이 함께 바뀐다.

레퍼런스에서 온 이름(Solarized·Nord·Dracula·Catppuccin·Gruvbox·Rosé Pine·Tokyo Night·Everforest)을 앱에 그대로 쓸지는 테마별 라이선스와 상표를 확인해 정한다. 못 쓰는 이름은 그 테마만 자체 이름으로 바꾸고 팔레트는 그대로 둔다.

## 2. 팔레트

DP-1.2 에서 확정한다. 컨셉마다 유저가 보는 핵심 색(배경 단계·텍스트 단계·강조색·선택일·오늘·주말과 공휴일·이벤트 텍스트)을 정하고, 대표 화면 네 개의 목업으로 비교해 유저 승인을 받는다.

확정 시 지킬 것은 넷이다.

- 대비 검사 쌍(#461 작전계획 4항)이 전부 기준을 넘는다 — 글자와 배경 조합 열둘은 4.5:1, 주말·공휴일 강조색과 강조색은 3:1 이다.
- 같은 밝기 계열 안에서 어느 두 테마도 배경색과 강조색이 겹치지 않는다. 지금 남은 겹침은 두 쌍이다 — 솔라라이즈드 라이트와 에버포레스트 라이트는 배경이 같고, 카푸치노 모카와 도쿄 나이트는 둘 다 푸른 보라 계열이다.
- 레퍼런스 원본 값 중 대비 검사 쌍에 못 미치는 것은 기준에 맞게 올린다. 원본 그대로 걸리는 테마는 일곱이다 — 솔라라이즈드 라이트·다크, 노드 라이트, 카푸치노 라테, 로즈 파인 던, 에버포레스트, 에버포레스트 라이트.
- 기본 이벤트 태그 두 색(기본 `#088CDA`, 공휴일 `#D6236A` — `Domain/Sources/Models/Settings/AppearanceSettings.swift:27`)이 배경 위에서 읽힌다. 태그는 점과 막대로 그려서 3:1 로 본다. 원본 그대로 걸리는 테마는 셋이고 전부 공휴일 분홍이 묻힌다 — 노드 2.56:1, 드라큘라 2.92:1, 에버포레스트 2.56:1. 셋은 배경을 띄워 기준을 넘긴다.
