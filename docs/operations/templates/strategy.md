# 전략 지침 (Strategic Guidance) — XL

> 용어 — DP: 결정적 지점(작전명령 하나 = PR 하나) · LOE: 노력선(최종상태 한 관점을 담당하는 줄기) · FRAGO: 단편명령 · MOP / MOE: 과업 수행 여부 / 효과 발생 여부 · PIR / FFIR: 즉시보고 조건 중 환경·외부 정보 / 아군·내부 정보 · ends / ways / means: 목적 / 캠페인 / 자원

```
전략 지침 — #<상위이슈> <명칭>        작성: 유저   개정:
1. 목적 (ends) — 이 묶음이 끝나면 무엇이 달라지나
2. 최종상태 (완료형 + 판정 방법)
3. 종결·중단 기준 — 성공 종결 (= 2항 도달) / 중단·축소 조건 / 중단 시 수습 (종결·진행 캠페인 처리)
4. 수단·제한 (means) — 적용 rules 출처 / 이 묶음 특유의 해야·하지 말아야 (이유) / ends-ways-means-risk 정합 — 수단이 목적에 못 미치면 목적 축소 또는 위험 수용을 명시
5. 위임 상한 — 결정 권한표 기준 + 넓히거나 좁히는 것
6. 캠페인 목록 (ways) | 캠페인 | 이슈# | 목적 | 선행 | 순서 근거 |
7. 캠페인 배열 — 직렬·병렬·조건부 착수 / 주노력 캠페인 (자원 우선) / 가정 조기 검증 순서
   요도 — 캠페인 배열을 mermaid flowchart 로: 캠페인 = 노드, 선행 = 실선, 조건부 착수 = 결정지점 라벨 점선 (campaign.md 8항과 같은 파생 규칙)
8. 전략 가정 | ID | 가정 | 검증 방법 | 깨지면 (결정지점 ID — 없으면 재검토) |
9. 전략 위험 | 위험 | 영향 캠페인 | 수용·완화·회피 | 근거 |
   한계점 — 동시 진행 캠페인 수·유저 재가 처리량 등 "여기 넘으면 신규 착수 중단" 지점 + 지표
10. 전략 결정지점 | ID | 판단 정보 | 결정 (캠페인 재배열·취소·재평가) | 미결 시 기본 |
11. 평가 — 캠페인 MOE 합산 → 목적 달성 판정 / 재평가 트리거 (캠페인 종결 + 전략 가정 붕괴·외부 환경 변화)
12. 캠페인 원장 → .operations/<이슈>/strategy-progress.md — 원장 표 | 캠페인 | 상태 미착수/진행/종결 | 최근 종결보고 | 비고 | (커밋되지 않음, 이슈 본문 <!-- progress --> 블록으로 미러)
```

- 6 은 정의(계획 변경 때만 이 파일 개정), 12 는 상태 — 진행 파일에서 캠페인 착수·종결마다 자유 갱신. 이슈 본문 = 이 파일 전문 + <!-- progress --> 블록
