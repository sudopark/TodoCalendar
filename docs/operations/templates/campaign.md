# 작전계획 (Campaign Plan) — L

> 용어 — DP: 결정적 지점(작전명령 하나 = PR 하나) · LOE: 노력선(최종상태 한 관점을 담당하는 줄기) · FRAGO: 단편명령 · MOP / MOE: 과업 수행 여부 / 효과 발생 여부 · PIR / FFIR: 즉시보고 조건 중 환경·외부 정보 / 아군·내부 정보 · branch / sequel: 결정지점에서 발동하는 단계 안 대체 경로 / 단계 종료 상태별 후속 경로

```
작전계획 — #<상위이슈> <명칭>        작성: 유저   개정:

0. 전략 지침 — 목적 (상위 이슈 # 또는 strategy.md 인용) / 수단·제한 출처 / 위임 상한
1. 상황 — 정찰 요약 (계획에 영향 주는 것만, file:line — kickoff 탐색 재사용) / 장애·마찰 — 유력한 양상 / 가장 위험한 양상
2. 문제 정의 — 현 상태 / 원하는 상태 / 막는 것 / 범위 밖
3. 종결·중단 기준 — 성공 종결 (= 4항 도달) / 중단·축소 조건 (무엇이 깨지면 캠페인 자체를 재검토하나) / 중단 시 수습 (머지된 DP·열린 브랜치 처리)
4. 최종상태 (완료형 + 판정 방법) | 관점 동작·코드·구조·검증·품질·외부 | 상태 | 판정 |
5. 중심 분석 — 힘의 원천 / 장애의 중심 + 취약점 / 접근 직접·우회·잠식 — 왜 (COA 비교 선택 근거 포함)
6. 노력선 LOE-n <명칭>: 담당 관점 → 중간 목표 ① → ② → ③
7. 단계 (조건은 상태로) | 단계 | 진입 조건 | 종료 조건 | 주노력 LOE | 목적 |
   sequel — 종료 상태별 후속 (충족 → 다음 단계 / 부분·미충족 → <경로>) — 갈리는 단계만
8. 작전 배열 — 노력선 × 단계 격자 → DP 좌표
   시퀀스 — 병렬 묶음·직렬 사슬 + 근거 (선행 의존 / 가정 조기 검증 / 한계점) — 병렬 슬롯 대응
   통제수단 — 인접 DP 사이 인터페이스 계약·머지 순서 (마찰 지점만)
9. DP 목록 | DP | LOE | 단계 | 내용 | 선행 DP | 소유 범위 (모듈·파일) | 사이즈 S/M |
10. 결정지점·branch | ID | 판단 정보 PIR/FFIR | 결정 | 시한 (조건) | 미결 시 기본 |
    branch | 발동 결정지점 | 내용 (DP 재배열·대체·범위 축소까지 — 태스크 수준 우발은 opord 소관) | 결심자 |
11. 가정 | ID | 가정 | 검증 방법 (어느 DP·검증이 조기 확인하나) | 깨지면 (결정지점·branch ID — 없으면 재검토 상향) |
12. 위험 | 위험 | 영향 LOE | 수용·완화·회피 (branch ID 가능) | 근거 |
    작전한계점 — "여기 넘으면 신규 착수를 멈추고 소화" 지점 + 지표 (리뷰 대기 PR 수·재가 처리량·브랜치 발산 등)
13. 자원 | 단계 | 주노력 자원 | 부노력 자원 |   — 병렬 슬롯·워크트리·외부 계정·유저 시간
14. 평가 — MOP (DP 완료 판정) / MOE | 관점 | 지표 | 판정 데이터 출처 (테스트·스냅샷·실기동·사용 지표) | / 평가 시점 (종결보고·단계 전환)
15. 위임 — delegation.md 상속, 좁히는 것만 기재
16. 상시 제한 — 해야 (이유) / 하지 말아야 (이유)
17. 상시 즉시보고 조건 — 조건마다 대응 결정지점(10항 ID) 필수. 기본 항목: 제한·위임 판단이 갈리는데 rules 조항 없음 → 하네스 갭
18. 원장 → .operations/<상위이슈>/campaign-progress.md — 원장 표 | DP | 상태 미착수/착수/실행/검토/머지 | 이슈# | 브랜치 | base | PR# | 비고 | + 현재 국면 줄 (커밋되지 않음, 이슈 본문 <!-- progress --> 블록으로 미러)
```

- 9 는 정의(계획 변경 때만 이 파일 개정), 18 은 상태 — 진행 파일에서 착수·PR 생성·종결보고·머지마다 자유 갱신. 이슈 본문 = 이 파일 전문 + <!-- progress --> 블록
- DP 는 "PR 하나로 며칠 안에 끝나는 크기"까지 쪼갠다. 안 쪼개지면 그 DP 가 하위 캠페인이다
- M 사이즈는 이 문서를 만들지 않는다 — 0·2·4·11·15·16·17 을 작전명령 1-다 에 한 줄씩
