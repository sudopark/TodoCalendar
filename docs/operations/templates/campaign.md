# 작전계획 (Campaign Plan) — L

> 용어 — DP: 결정적 지점(작전명령 하나 = PR 하나) · LOE: 노력선(최종상태 한 관점을 담당하는 줄기) · FRAGO: 단편명령 · MOP / MOE: 과업 수행 여부 / 효과 발생 여부 · PIR / FFIR: 즉시보고 조건 중 환경·외부 정보 / 아군·내부 정보

```
작전계획 — #<상위이슈> <명칭>        작성: 유저   개정:   현재 국면: <n>단계

0. 전략 지침 — 목적 (상위 이슈 # 또는 strategy.md 인용) / 수단·제한 출처 / 위임 상한
1. 문제 정의 — 현 상태 / 원하는 상태 / 막는 것 / 범위 밖
2. 최종상태 (완료형 + 판정 방법) | 관점 동작·코드·구조·검증·품질·외부 | 상태 | 판정 |
3. 중심 분석 — 힘의 원천 / 장애의 중심 + 취약점 / 접근 직접·우회·잠식 — 왜
4. 노력선 LOE-n <명칭>: 담당 관점 → 중간 목표 ① → ② → ③
5. 단계 (종료 조건은 상태로) | 단계 | 종료 조건 | 주노력 LOE | 목적 |
6. 노력선 × 단계 격자 → DP 좌표
   통제수단 — 인접 DP 사이 인터페이스 계약·머지 순서 (마찰 지점만)
7. DP 목록 | DP | LOE | 단계 | 내용 | 선행 DP | 소유 범위 (모듈·파일) | 사이즈 S/M |
8. 가정 | ID | 가정 | 검증 방법 | 깨지면 |
9. 위험 | 위험 | 영향 LOE | 수용·완화·회피 | 근거 |
10. 자원 | 단계 | 주노력 자원 | 부노력 자원 |   — 병렬 슬롯·워크트리·외부 계정·유저 시간
11. 평가 — MOP (DP 완료 판정) / MOE (관점별 효과 판정) / 평가 시점 (종결보고·단계 전환)
12. 위임 기본값 (하위 작전명령 상속 — 좁히기만) | 사안 | 자율 | 사후보고 | 사전승인 |
13. 상시 제한 — 해야 (이유) / 하지 말아야 (이유)
14. 상시 즉시보고 조건 — 기본 항목: 제한·위임 판단이 갈리는데 rules 조항 없음 → 하네스 갭
15. 원장 | DP | 상태 미착수/착수/실행/검토/머지 | 이슈# | 브랜치 | base | PR# | 비고 |
```

- 7 은 정의(계획 변경 때만), 15 는 상태(착수·PR 생성·종결보고·머지마다). 이슈 본문은 이 파일의 미러
- DP 는 "PR 하나로 며칠 안에 끝나는 크기"까지 쪼갠다. 안 쪼개지면 그 DP 가 하위 캠페인이다
- M 사이즈는 이 문서를 만들지 않는다 — 0·1·2·8·12·13·14 를 작전명령 1-다 에 한 줄씩
