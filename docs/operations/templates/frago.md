# 변경 지시 (FRAGO) — 작업 지침 부록 D 항목

게시: 발부마다 전문을 이슈 봇 코멘트로 기록 (히스토리 층 — 멘션 없음). 부록 D 누적·`핵심:` 줄 갱신·미러 재조립·board-sync 와 한 묶음 (opord §6)

```
FRAGO-<n>     발령: 에이전트 | 유저   시각:   승인: 사전 | 사후
사유:      우발 <X> / 가정 A-<n> 붕괴 / 긴급 보고 <FFIR-n> / 플랜 갭 / 인접 DP 침범 통보 접수
변경 항목: 2항 K-<n> / T-<n> / 부록 B 커밋 <n>
변경:      이전 → 이후
변경 없음: 나머지 전부
상향:      없음 / campaign.md <항목> 재검토 요청
```

■ 핵심의 `왜`·`뭘`·`최종상태`가 바뀌면 변경 지시가 아니라 재작성. `어떻게`(핵심 변경·꼭지 구성)는 변경 지시로 갱신한다.
