# 단편명령 (FRAGO) — 작업 지침 부록 D 항목

게시: 발부마다 전문을 이슈 봇 코멘트로 기록 (히스토리 층 — 멘션 없음). 부록 D 누적·`핵심:` 줄 갱신·미러 재조립·board-sync 와 한 묶음 (opord §6)

```
FRAGO-<n>     발령: 에이전트 | 유저   시각:   승인: 사전 | 사후
사유:      우발 <X> / 가정 A-<n> 붕괴 / 즉시보고 <FFIR-n> / 플랜 갭
변경 항목: 3-다 T-<n> / 부록 B 커밋 <n>
변경:      이전 → 이후
변경 없음: 나머지 전부
상향:      없음 / campaign.md <항목> 재검토 요청
```

의도(3-가)가 바뀌면 단편명령이 아니라 재작성.
