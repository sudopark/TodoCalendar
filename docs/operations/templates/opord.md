# 작전명령 (Operation Order) — M · DP

> 용어 — DP: 결정적 지점(작전명령 하나 = PR 하나) · LOE: 노력선(최종상태 한 관점을 담당하는 줄기) · FRAGO: 단편명령 · MOP / MOE: 과업 수행 여부 / 효과 발생 여부 · PIR / FFIR: 즉시보고 조건 중 환경·외부 정보 / 아군·내부 정보

```
작전명령 — #<이슈> <명칭>       초안: 에이전트   재가: 유저   일자:   상태: 초안/재가/실행/종결
상위: campaign.md #<n> / LOE-<x> / <y>단계 / DP-<x.y> / 선행 DP     (M 이면 "단독")

■ 확인보고 — 임무 / 의도 / 자율로 정할 것 / 묻는 것

1. 상황
   가. 정찰 결과 — 계획에 영향 주는 것만, file:line (kickoff 탐색 재사용)
   나. 장애·마찰 — 유력한 양상 / 가장 위험한 양상
   다. 상위 인용 — 최종상태 관련 관점 / 노력선 중간 목표 / 인접 DP 관계·인터페이스 계약
       (M: 목적·문제 정의·최종상태·가정·위임·제한 각 한 줄)
   라. 가정 | ID | 가정 | 출처 상속/신규/미확인 질문 대체 | 깨지면 |
2. 임무 — 이 작업은 <조건>까지 <과업동사 + 대상>하여, <노력선 중간 목표 / 상위 목적>한다.
3. 실시
   가. 의도 — 목적 / 핵심과업 (성립 조건, 방법 X) / 최종상태 (동작·코드·구조·검증·외부)
   나. 개념 — 결정적 행동 (하나) / 여건 조성 / 대안 경로 + 전환 조건 / 단계 (상태 조건)
   다. 과업 — T-n: <과업동사 + 대상>하여, <목적>. (상세 부록 A)
   라. 협조지시 (이유 없는 항목은 삭제)
       개시 조건 / 인터페이스 계약 (상속 + 추가) / 제한 (이유) / 위임 범위 (좁히는 것만) / 수용 위험
       버퍼 — 실행자 재량 폭 = 자율 등급 + 아래 우발계획
       즉시보고 조건  PIR-n (환경·외부) → 결정지점 D-n / FFIR-n (아군·내부) → 결정지점 D-n
       결정지점 | ID | 결정 | 판단 정보 | 시한(조건) | 미결 시 기본 행동 |
       우발계획 | 조건 | 행동 | 결심자 | 상향 |
4. 검증·자원 — 테스트 스킴·검증 사다리 / 스냅샷·실기 / 모델 티어·병렬 슬롯·워크트리 / 외부 자원
5. 보고 — 즉시 (조건·우발·가정 붕괴·하네스 갭) / 정기 (단계 전환·태스크 완료) / 유저 부재 시 (의도 안이면 기본안으로 계속, <조건>이면 중단) / 종결 조건

부록 A. 태스크 상세 — `### Task N: <제목>` 헤딩(SDD task-brief 호환) · Files · Interfaces · 체크박스 Step / 시그니처·경로·동형 file:line·엣지 케이스·테스트 케이스 이름
부록 B. 커밋 시퀀스 (변경은 사후보고)
부록 C. 모델 티어 표
부록 D. 단편명령 누적
부록 E. 진행 | 태스크 | 상태 | 커밋 | 보고 |
```

- 쓰는 순서: 2 임무 → 3-가 → 3-나 → 3-다 → 3-라 → 1 → 4·5. 3-가 ≥ 3-다 (과업이 더 길면 방법을 지시하고 있는 것)
- 정찰로 알 수 있는 건 묻지 않는다. 못 물은 건 1-라 "미확인 질문 대체" 가정으로 박고 초안을 내보낸다
- 재가에서 유저는 의도와 어긋난 부분만 고친다. 방법 지정 허용은 셋뿐: sub-work 동기화 / CLAUDE.md·rules 로 재량 없음 / 공유 자원 순서
